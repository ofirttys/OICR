Integrated Implementation Science Frameworks

Evaluating OTC Provision in Paediatric Oncology Care

REACH
Number, proportion & representativeness of participants
Assessment: Track eligible patients completing each OTC care pathway step.

Overlap: Related to Proctor's "Penetration"
EFFECTIVENESS
Achievement of intended outcomes
Assessment: Impact on patients and caregivers, care experience quality, rationales for OTC decisions.

Overlap: Links to TfA's "Perceived Effectiveness"
ADOPTION
Number, proportion & representativeness of settings/providers
Assessment: Pathway completion across divisions, provider integration into practice.

Overlap: Core Proctor Implementation Outcome
IMPLEMENTATION
Process, fidelity, adaptations
Assessment: Implementation strategies, process description, adaptations made. Informed by CFIR domains.

Overlap: Related to Proctor's "Fidelity"
MAINTENANCE
Extent integrated into routine practice
Assessment: Sustainability potential, resources needed for continuation.

Overlap: Related to Proctor's "Sustainability"

Framework Integration & Relationships
RE-AIM provides the overarching evaluation structure with five dimensions guiding comprehensive assessment of implementation impact.
CFIR informs the Implementation dimension by identifying barriers and enablers across five domains that affect program delivery.
Proctor's Taxonomy defines specific implementation outcomes, with several overlapping RE-AIM dimensions (Adoption, Penetration/Reach, Sustainability/Maintenance, Fidelity/Implementation).
TfA operationalizes Acceptability (a Proctor outcome) through seven measurable constructs assessed among patients, caregivers, and providers.
Formative Evaluation uses findings from all frameworks to inform ongoing implementation refinements and strategy adjustments.
Summative Evaluation assesses overall implementation success at study end using all framework dimensions to inform optimization and sustainability.
